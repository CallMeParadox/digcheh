# پروژه نیتیو اندروید دیگچه | Digcheh Android Project 📱

این پروژه یک اپلیکیشن کامل و آماده‌ی بیلد نیتیو اندروید (Android Studio / Gradle) برای اپلیکیشن **«دیگچه»** است. تمامی دارایی‌ها، منطق محاسبات متابولیک و دیتابیس غذاهای ایرانی به صورت آفلاین داخل پوشه `assets/` قرار دارند و برای اجرا در گوشی به هیچ اینترنتی نیاز ندارند.

---

## ۱. ساختار پروژه اندروید
```
digcheh-android/
├── app/
│   ├── build.gradle
│   └── src/main/
│       ├── AndroidManifest.xml (پکیج: com.digcheh.app - نام: دیگچه)
│       ├── java/com/digcheh/app/MainActivity.java (اکتیویتی نیتیو با شتاب‌دهنده سخت‌افزاری و استاتوس‌بار سازگار)
│       ├── assets/ (فایل‌های index.html، app.js و foods.json آفلاین)
│       └── res/ (رشته‌های فارسی، استایل‌ها و رنگ زمردی)
├── build.gradle
└── settings.gradle
```

## ۲. روش‌های ساخت فایل خروجی APK

### روش اول: با اندروید استودیو (Android Studio - آسان‌ترین روش)
1. نرم‌افزار **Android Studio** را باز کنید.
2. گزینه **Open** را بزنید و پوشه زیر را انتخاب کنید:
   `C:\Users\HP\.gemini\antigravity\scratch\digcheh-android`
3. از منوی بالای اندروید استودیو گزینه زیر را انتخاب کنید:
   **Build > Build Bundle(s) / APK(s) > Build APK(s)**
4. فایل `app-debug.apk` ظرف چند ثانیه تولید شده و می‌توانید آن را مستقیماً روی گوشی نصب کنید.

### روش دوم: با دستور ترمینال (Gradle)
```bash
gradlew.bat assembleDebug
```
فایل خروجی APK در مسیر زیر ساخته می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`

## ۳. نصب آنی روی گوشی موبایل اندروید بدون نیاز به بیلد (PWA Native)
اگر می‌خواهید همین الان برنامه را بدون نصب اندروید استودیو روی موبایل خود به صورت اپلیکیشن نصبی داشته باشید:
1. گوشی و کامپیوتر را به یک وای‌فای مشترک وصل کنید.
2. با مرورگر کروم در گوشی، آدرس IP کامپیوتر را وارد کنید (مثلاً `http://192.168.1.X:5050/index.html`).
3. از منوی سه نقطه کروم، دکمه **«افزودن به صفحه اصلی» (Install App / Add to Home screen)** را بزنید.
4. آیکون برنامه «دیگچه» به عنوان یک اپ مستقل و فول‌اسکرین در لیست برنامه‌های گوشی شما اضافه می‌شود.
