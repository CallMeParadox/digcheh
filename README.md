# اپلیکیشن کاملاً نیتیو اندروید دیگچه | Digcheh 100% Native Android App 📱🍲

این پروژه پیاده‌سازی **۱۰۰٪ نیتیو اندروید (Pure Native Android)** بدون استفاده از هیچ‌گونه وب‌ویو، HTML یا جاوااسکریپت است. تمام کامپوننت‌ها با استفاده از متریال کامپوننت‌های رسمی اندروید (Google Material Design Components)، لایوت‌های نیتیو XML و کد جاوا بازنویسی شده‌اند.

---

## ۱. ساختار کاملاً نیتیو (Pure Native Architecture)
```
digcheh-android/
├── app/
│   ├── build.gradle (شامل کتابخانه‌های رسمی AndroidX و Google Material)
│   └── src/main/
│       ├── AndroidManifest.xml (پکیج: com.digcheh.app)
│       ├── java/com/digcheh/app/
│       │   ├── MainActivity.java (اکتیویتی اصلی نیتیو، مدیریت لایوت‌ها و فرمت اعداد فارسی)
│       │   ├── DataManager.java (مدیریت دیتابیس لوکال و ذخیره‌سازی در SharedPreferences)
│       │   ├── FoodItem.java (مدل داده غذاها و واحدهای مصرفی)
│       │   ├── LoggedFood.java (مدل رکوردهای ثبت‌شده در وعده‌ها)
│       │   └── FoodSearchAdapter.java (آداپتر RecyclerView برای جستجوی لایو غذاها)
│       ├── res/
│       │   ├── layout/
│       │   │   ├── activity_main.xml (داشبورد اصلی نیتیو و ماتریس بنتو)
│       │   │   ├── item_meal_food.xml (آیتم غذا در وعده با انیمیشن اکاردئونی ماکروها)
│       │   │   ├── bottom_sheet_add_food.xml (باتم‌شیت متریال برای افزودن غذا)
│       │   │   ├── item_food_search.xml (آیتم پیشنهادات جستجو)
│       │   │   └── dialog_cheat_meal.xml (دیالوگ نیتیو تنظیم چیت‌میل)
│       │   ├── drawable/ (آیکون‌های کاملاً وکتور نیتیو اندروید بدون هیچ ایموجی)
│       │   └── values/ (رنگ‌های اختصاصی زمردی، رشته‌ها و تم‌های متریال)
│       └── assets/
│           └── foods.json (بانک غذایی)
├── build.gradle
└── settings.gradle
```

## ۲. ویژگی‌های نسخه نیتیو
- **عملکرد ۱۲۰ هرتز و انیمیشن‌های فوق روان:** اسکرول و ترنزیشن‌های کاملاً روان با سخت‌افزار نیتیو گوشی.
- **ماتریس انرژی بنتو (Bento Matrix):** نوار پیشرفت سفارشی با گوشه‌های گرد و ۳ میکروکارت پروتئین، کربوهیدرات و چربی.
- **۴ وعده غذایی مجزا:** هر وعده دارای دکمه «+ افزودن»، محاسبه سرجمع کالری و باز و بسته شدن جزئیات ماکرو با کلیک.
- **باتم شیت متریال برای ثبت غذا:** جستجوی آنی در بانک غذاهای ایرانی، انتخاب واحد مصرفی (کف دست، قاشق، عدد، گرم و...) و محاسبه خودکار.
- **پاپ‌اور تنظیم چیت‌میل:** انتخاب دوره استراحت (۳، ۵، ۷ یا ۱۴ روز).
- **امضای معتبر با Release Keystore:** بدون اخطار قرمز یا مسدودی توسط گوگل پلی‌پروتکت.
